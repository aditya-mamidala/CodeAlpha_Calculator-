# FORMULA — Premium Calculator

Responsive calculator built with vanilla HTML, CSS and JavaScript for the CodeAlpha Frontend Development task.

## Included
- `index.html` — interface markup
- `style.css` — premium styling and responsive layout
- `script.js` — calculator functionality

## Features
- Addition, subtraction, multiplication and division
- Decimal, sign toggle and percentage
- Keyboard support: digits, `+ - * /`, Enter, Backspace, Escape and `%`
- Calculation history with restore buttons
- Clear history and copy current result
- Dark/light theme toggle
- Responsive desktop, tablet and mobile design
- Division-by-zero handling

## GitHub upload
1. Extract this ZIP.
2. Open your `CodeAlpha_Calculator` repository.
3. Select **Add file → Upload files**.
4. Upload these four files to the repository root.
5. Commit the changes.
6. To publish, open **Settings → Pages** and deploy from the main branch and root folder.

Google Fonts are optional; fallback fonts are included.
